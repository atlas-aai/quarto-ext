## Quarto Templates for ATLAS

This repository provides Quarto custom formats for documents commonly produced by [Accessible Teaching, Learning, and Assessment Systems](https://atlas.ku.edu) (ATLAS) at the [University of Kansas](https://ku.edu).

| Format                                                                               | Usage                                                 |
|--------------------------------------------------------------------------------------|-------------------------------------------------------|
| [DLM Technical Report](https://github.com/atlas-aai/quarto-ext/tree/main/dlm-report) | `quarto use template atlas-aai/quarto-ext/dlm-report` |

These formats are published under the [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) public domain license.
